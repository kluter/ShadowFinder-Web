How ShadowFinder Web works
  1. Add a photo: drop, paste or browse. No photo? Type H and L.
  2. Mark 3 points: base, top, shadow tip. Drag to adjust.
  3. Check the time: EXIF fills it in; pick UTC or Local.
  4. Read the band: every place that shadow falls at that moment.
  5. Narrow it down: + adds the same place at another time; the overlap is the spot.
⚠ Reliable only when the shadow runs sideways across the frame (about 90°). The ∠ readout warns you.

Related: TracePoint, a companion tool for geolocation by line-of-sight intersection.
